
# 📘 AI Research Paper Review & Validation System

> A complete academic paper analysis, validation, and review generation system  
> Developed as part of **Infosys Springboard Virtual Internship**  
>
> 👤 **Author:** Likuna Swain

---

## 📌 Project Overview

The **AI Research Paper Review & Validation System** is an intelligent application that automates the process of:

- Searching research papers  
- Extracting academic content from PDFs  
- Analyzing and validating relevance  
- Generating structured academic sections  
- Providing visualization-based evaluation  
- Producing downloadable reports  

This project simulates a **real-world academic assistant** for students, researchers, and educators.

---

## 🎯 Objectives

- Automate research paper processing  
- Reduce manual review effort  
- Validate paper relevance to a chosen domain  
- Provide meaningful visual insights  
- Generate structured academic outputs  
- Store validation history for evaluation  

---

## 🧠 System Workflow

Upload PDF → Extract Text → Analyze Content →  
Validate Against Domain → Generate Sections →  
Visualize Results → Save & Download Report

---

## 🧩 Project Milestones

### ✅ Milestone 1: Research Paper Retrieval
- Environment setup  
- Semantic Scholar API integration  
- Automated research paper search  
- Download and storage of academic PDFs  
- Dataset preparation  

### ✅ Milestone 2: Text Extraction & Analysis
- PDF text extraction using PyMuPDF  
- Section-wise processing  
- Key findings extraction  
- Cross-paper comparison  
- Validation of extracted content  

### ✅ Milestone 3: Draft Generation
- Structured academic generation:
  - Abstract (100 words)
  - Methods comparison
  - Results synthesis  
- Content aggregation  
- Academic formatting  
- Preparation for review pipeline  

### ✅ Milestone 4: Final Integrated System
- Full interactive interface using Gradio  
- Upload research paper (PDF)  
- Domain selection (AI, Healthcare, Cybersecurity, Education)  
- Validation score generation  
- Graphical visualizations (charts)  
- Auto report saving  
- Downloadable report generation

## 🚀 How to Run the Project

1. Clone the repository:
   ```bash
   git clone <your-repo-link>
   cd your-project-folder
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   python app.py
   ```

4. Open the local Gradio URL shown in terminal.
